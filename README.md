# 🎓 ख्याति स्कॉलर्स अकादमी (Khyati Scholars Academy)

> **भारत की पहली AI-Powered English Coaching — Tier 2 & Tier 3 शहरों के लिए**

---

## 📌 परिचय (Overview)

ख्याति स्कॉलर्स अकादमी मालपुरा (राजस्थान) एवं Tier 2-3 कस्बों के छात्रों के लिए तैयार की गई एक आधुनिक **AI-Integrated English Education Portal** है। यह पोर्टल **Infosys Enterprise UI** शैली में डिज़ाइन किया गया है, जो उच्च स्तरीय दृश्य अनुभव, उत्तरदायी (Responsive) लेआउट और हिंदी भाषा सामग्री प्रदान करता है।

---

## ✨ मुख्य विशेषताएँ (Key Features)

- 🎨 **Infosys-Inspired Enterprise Layout**: नेविगेशन बार, हीरो सर्च बार, न्यूज़ टिकर, स्टोरीज़ कैरोसेल, AI सॉल्यूशंस कार्ड्स, केस स्टडीज़ एवं स्टैट्स काउंटर।
- 🤖 **KhyatiAI Chatbot**: छात्रों एवं अभिभावकों के प्रश्नों (फीस, दाखिला, कोर्स, फैकल्टी, स्थान) का हिंदी में उत्तर देने वाला 24/7 AI चैट विजेट।
- 📱 **Mobile & Tablet Responsive**: 320px से लेकर 4K मॉनिटर तक सभी डिवाइसेज पर सही रेंडरिंग।
- 🇮🇳 **हिंदी भाषा सामग्री**: Tier 2-3 दर्शक वर्ग के लिए संपूर्ण सामग्री शुद्ध और सुलभ हिंदी में।
- ⚡ **Zero External Dependencies**: Pure HTML5, Vanilla CSS3, और Modular JavaScript (No Heavy Frameworks).

## 🚀 लोकल सर्वर कैसे चलाएं (How to Run Locally)

### Python का उपयोग करके:
```bash
python -m http.server 8080 --bind 0.0.0.0
```
ब्राउज़र में खोलें: `http://localhost:8080`

### Node.js का उपयोग करके:
```bash
npx serve .
```
